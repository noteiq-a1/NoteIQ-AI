NOTEIQ AI WEBSITE PROTOTYPE

1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Click Upload PDF and try the workspace.

This is a frontend prototype. The AI replies are demo responses, not a real AI backend.
For the full app, connect:
Frontend -> Backend -> PDF extraction -> RAG/vector database -> LLM -> Answer.

Suggested stack:
Frontend: React/Next.js
Backend: Python FastAPI
PDF: PyMuPDF
RAG: embeddings + vector database
AI: LLM API
Database/Auth: Supabase or Firebase
